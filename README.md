# Reality's Minecraft mods

Six projects, each in its own folder with its own README and build.

| Folder | What it is |
|---|---|
| [MobCraft-Season3](MobCraft-Season3) | MobCraft Season 3 beta, a Fabric mod for Minecraft 26.3, with versions for 26.2, 26.1.2 and 1.21.4 to 1.21.11 in its `versions` folder: playable mobs with abilities and ultimates, RTS mode, teams, Gloamite gear, tiers, custom enchants, the Stronghold Tome, the Witch's Shadow and more. |
| [MobCraft-NeoForge](MobCraft-NeoForge) | MobCraft Season 3 for NeoForge: the same beta, built for NeoForge on every version from 1.21.4 to 26.3. |
| [MenuTrim](MenuTrim) | Menu Trim, a client mod that hides the Essential menu buttons you don't use. Built for every version Essential supports, 1.8.9 to 26.3, on Fabric, Forge and NeoForge. |
| [AutoDrinkOminousBottles](AutoDrinkOminousBottles) | Auto-Drink Ominous Bottles, a client mod that drinks an Ominous Bottle the moment a raid is won. Built for Fabric, Forge and NeoForge, 1.21 to 26.3. |
| [FightBot](FightBot) | Fight Bot, a Fabric mod for Minecraft 26.3 that adds a PvP practice bot with many kits and fighting styles. One build makes two jars: one that learns from each round and one that doesn't. |
| [Hafnium](Hafnium) | Hafnium, an open-source alternative to Essential for Fabric on Minecraft 26.3: a gray menu theme, movable buttons, friends and chat, world hosting with join codes, and a wardrobe of capes, skins and 3D cosmetics made by players. Includes its Cloudflare Worker server and sign-in helper. |
