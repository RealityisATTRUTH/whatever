# Reality's Minecraft mods

Two mods, each in its own folder with its own README and build.

| Folder | What it is |
|---|---|
| [MobCraft-Season3](MobCraft-Season3) | MobCraft Season 3 alpha, a Fabric mod for Minecraft 26.3: playable mobs with abilities and ultimates, RTS mode, teams, the Mob Guide and more. |
| [MenuTrim](MenuTrim) | Menu Trim, a client mod that hides the Essential menu buttons you don't use. Built for every version Essential supports, 1.8.9 to 26.3, on Fabric, Forge and NeoForge. |
