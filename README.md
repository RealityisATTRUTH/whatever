# Reality's Minecraft mods

Four mods, each in its own folder with its own README and build.

| Folder | What it is |
|---|---|
| [MobCraft-Season3](MobCraft-Season3) | MobCraft Season 3 beta, a Fabric mod for Minecraft 26.3: playable mobs with abilities and ultimates, RTS mode, teams, Gloamite gear, tiers, custom enchants, the Stronghold Tome, the Witch's Shadow and more. |
| [MenuTrim](MenuTrim) | Menu Trim, a client mod that hides the Essential menu buttons you don't use. Built for every version Essential supports, 1.8.9 to 26.3, on Fabric, Forge and NeoForge. |
| [AutoDrinkOminousBottles](AutoDrinkOminousBottles) | Auto-Drink Ominous Bottles, a client-side Fabric mod. The imported upstream build currently targets Minecraft 26.1.2; other versions are not yet included. |
| [FightBot](FightBot) | Fight Bot, a Fabric mod for Minecraft 26.3 that adds a PvP practice bot with many kits and fighting styles. One build makes two jars: one that learns from each round and one that doesn't. |
